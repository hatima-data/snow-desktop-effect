# ❄️ Snow Desktop Effect (Mini-App)

An interactive, lightweight desktop application for Windows and macOS that activates a cozy snowfall effect across your screen, displaying snowflakes over all open windows to create a festive winter atmosphere

## 📥 Installation & How to Run (Windows)

1. Download the archive or folder from this repository.
2. Extract (unzip) the downloaded archive.
3. Open the folder and run **Snowdesk-x86_64.exe** (for 64-bit systems)
4. *Note:* On the first launch, Windows Defender SmartScreen may show a security warning. Click "More info" (*Подробнее*) and then "Run anyway" (*Выполнить в любом случае*)

## ⚙️ Controls & Settings
Once launched, a small app icon will appear in your system tray (near the clock). Right-clicking the icon allows you to:
* Switch snowfall modes (*Light snow*, *Cozy snow*, *Blizzard*)
* Toggle the *Snowman* effect
* Pause the snowfall or completely *Exit* the application.

## 💻 System Requirements
* OS: Windows or macOS
* Performance: Ultra-lightweight (~60 KB), runs smoothly without affecting system performance.
