# ❄️ Snow Desktop Effect (Mini-App)

An interactive, lightweight desktop application for Windows and macOS that activates a cozy snowfall effect across your screen, displaying snowflakes over all open windows to create a festive winter atmosphere[span_0](start_span)[span_0](end_span)[span_1](start_span)[span_1](end_span).

## 📥 Installation & How to Run (Windows)

1. Download the archive or folder from this repository.
2. Extract (unzip) the downloaded archive.
3. Open the folder and run **Snowdesk-x86_64.exe** (for 64-bit systems)[span_2](start_span)[span_2](end_span).
4. *Note:* On the first launch, Windows Defender SmartScreen may show a security warning[span_3](start_span)[span_3](end_span). Click "More info" (*Подробнее*) and then "Run anyway" (*Выполнить в любом случае*)[span_4](start_span)[span_4](end_span).

## ⚙️ Controls & Settings
Once launched, a small app icon will appear in your system tray (near the clock). Right-clicking the icon allows you to:
* Switch snowfall modes (*Light snow*, *Cozy snow*, *Blizzard*)[span_5](start_span)[span_5](end_span).
* Toggle the *Snowman* effect[span_6](start_span)[span_6](end_span).
* Pause the snowfall or completely *Exit* the application[span_7](start_span)[span_7](end_span).

## 💻 System Requirements
* OS: Windows or macOS[span_8](start_span)[span_8](end_span)
* Performance: Ultra-lightweight (~60 KB)[span_9](start_span)[span_9](end_span), runs smoothly without affecting system performance.
